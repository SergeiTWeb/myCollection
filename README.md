# Веб-приложение «Моя коллекция музыки» v.1.0

Современное полнофункциональное (full-stack) веб-приложение для каталогизации, управления и поиска физических музыкальных носителей (CD, виниловых пластинок и аудиокассет). Разработано с упором на безопасность, адаптивный дизайн и бесшовный пользовательский опыт.

## Возможности

- **Интеграция с Discogs API**:
  Поиск музыкальных релизов в реальном времени с фильтрацией по форматам (CD, винил, кассета).
- **Безопасная аутентификация**:
  Регистрация по email и паролю с использованием сессий на основе JWT и подтверждением адреса электронной почты (через Nodemailer).
- **Управление двумя списками**:
  Отдельные представления «Коллекция» и «Список желаемого» (Wishlist) с возможностью бесшовного перемещения элементов между ними.
- **Динамический интерфейс**:
  Переключение между режимами отображения «Сетка» (1, 2 или 3 колонки) и «Список» для удобного просмотра больших коллекций.
- **Персонализация**:
  Добавление, редактирование и сохранение личных заметок для каждого релиза.
- **Портативность данных**:
  Экспорт всей коллекции в формат CSV одним кликом для офлайн-резервного копирования или анализа в электронных таблицах.
- **Темизация**:
  Встроенное переключение между светлой и темной темами с сохранением выбранного состояния.
- **Адаптивный дизайн**:
  Полная оптимизация для просмотра на мобильных устройствах, планшетах и настольных компьютерах.

## Технологический стек

### Frontend

- **React 18**: Компонентная библиотека для создания пользовательского интерфейса.
- **Vite**: Инструмент нового поколения для молниеносно быстрой фронтенд-разработки.
- **React Router DOM**: Клиентская маршрутизация для создания бесшовного одностраничного приложения (SPA).
- **Modern CSS**: Пользовательские CSS-переменные для темизации, Flexbox и CSS Grid для адаптивных макетов (без тяжелых фреймворков вроде Bootstrap, что обеспечивает уникальную эстетику «художественной галереи»).

### Backend

- **Node.js & Express**: Надежная серверная среда и фреймворк для создания RESTful API.
- **MySQL (via `mysql2`)**: Реляционная база данных для структурированного и постоянного хранения данных.
- **JWT (JSON Web Tokens)**: Безопасная аутентификация пользователей без сохранения состояния (stateless).
- **Bcrypt**: Отраслевой стандарт хеширования паролей (10 раундов хеширования).
- **Nodemailer**: Автоматическая отправка электронных писем для подтверждения аккаунта // возможна только в localhost версии на данном этапе.

### Архитектура и безопасность

- **Backend-for-Frontend (BFF) Proxy**: Ключи Discogs API строго изолированы на бэкенде. Фронтенд никогда не раскрывает конфиденциальные учетные данные.
- **Parameterized Queries**: Все взаимодействия с базой данных используют плейсхолдеры `?`, что гарантирует надежную защиту от атак типа SQL-инъекция.
- **Row-Level Security**: Каждый запрос к базе данных ограничивается аутентифицированным `user_id`, обеспечивая строгую изоляцию данных между пользователями.

## Установка и настройка

### Предварительные требования

- Node.js (v18 или выше)
- MySQL Server (v8.0 или выше)
- Аккаунт разработчика Discogs (для получения ключей API)
- Аккаунт Gmail с включенным «Паролем приложений» (App Password) (для подтверждения email)

### 1. Клонирование репозитория

```bash
git clone https://github.com/SergeiTWeb/myCollection.git
cd myСollection
```

### 2. Настройка базы данных

Шаг 1: Установка локального сервера MySQL
Рекомендуемый способ - использовать Homebrew (MacOS) или XAMPP/MAMP.

- Скачайте и установите XAMPP или MAMP. Запустите приложение и нажмите "Start" для MySQL.

Шаг 2: Создание базы данных (в моём примере используется HeidiSQL)

1. Откройте HeidiSQL.
2. Создайте новое подключение:
   - Сетевой тип: MySQL (TCP/IP)
   - Хост: 127.0.0.1 (или localhost)
   - Пользователь: root
   - Пароль: оставьте пустым (или root, если используете MAMP/XAMPP).
   - Подключитесь.

3. В появившемся окне: Файл -> Создать -> Базу Данных
4. Назовите её, например, mycollection_local. Кодировка: utf8mb4.
5. Выберите эту новую базу данных, перейдите на вкладку Запрос (Query) и вставьте мастер-скрипт для создания таблиц:

```bash

-- ==========================================
-- 1. Таблица пользователей (Users)
-- ==========================================
CREATE TABLE IF NOT EXISTS users (
id INT AUTO_INCREMENT PRIMARY KEY,
email VARCHAR(255) NOT NULL UNIQUE,
password_hash VARCHAR(255) NOT NULL,
is_verified BOOLEAN DEFAULT TRUE,
verification_token VARCHAR(255) DEFAULT NULL,
created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- ==========================================
-- 2. Таблица коллекции (Collection)
-- ==========================================
CREATE TABLE IF NOT EXISTS collection (
id INT AUTO_INCREMENT PRIMARY KEY,
user_id INT NOT NULL,
discogs_id VARCHAR(100) DEFAULT NULL,
title VARCHAR(255) NOT NULL,
year VARCHAR(10) DEFAULT '',
cover_image LONGTEXT DEFAULT NULL,
format VARCHAR(50) DEFAULT 'CD',
notes TEXT DEFAULT NULL,
added_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    -- Связь с таблицей users (при удалении пользователя удаляются и его записи)
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,

    -- Индекс для ускорения поиска по пользователю
    INDEX idx_user_id (user_id)

) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- ==========================================
-- 3. Таблица списка желаемого (Wishlist)
-- ==========================================
CREATE TABLE IF NOT EXISTS wishlist (
id INT AUTO_INCREMENT PRIMARY KEY,
user_id INT NOT NULL,
discogs_id VARCHAR(100) DEFAULT NULL,
title VARCHAR(255) NOT NULL,
year VARCHAR(10) DEFAULT '',
cover_image LONGTEXT DEFAULT NULL,
format VARCHAR(50) DEFAULT 'CD',
added_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    -- Связь с таблицей users
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,

    -- Индекс для ускорения поиска по пользователю
    INDEX idx_user_id (user_id)

) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

```

6. Нажмите "Выполнить" (Run).

### 3. Настройка бэкенда

```bash
cd backend
npm install
```

1. Создайте файл .env в директории backend и добавьте свои учетные данные:

```bash
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_mysql_password
DB_NAME=cd_catalogue_db
PORT=3001

DISCOGS_KEY=your_discogs_consumer_key
DISCOGS_SECRET=your_discogs_consumer_secret

JWT_SECRET=your_super_secret_jwt_key
EMAIL_USER=your_email@gmail.com
EMAIL_PASS=your_16_digit_gmail_app_password
```

- (Убедитесь, что в Google reCAPTCHA Console в список разрешенных доменов добавлен localhost, иначе капча не пройдет).

2. Запустите сервер бэкенда:

```bash
npm run dev
```

Вы должны увидеть: Backend running on http://localhost:3001.

### 4. Настройка фронтенда

1. Откройте новое окно терминала:

```bash
cd frontend # (or the root directory if Vite is in the root)
npm install
npm run dev
```

- Откройте http://localhost:5173 в вашем браузере.

### Руководство пользователя

- Регистрация: Создайте аккаунт, используя действительный адрес электронной почты.
- Подтверждение: Проверьте входящие сообщения электронной почты и перейдите по ссылке для подтверждения, чтобы активировать аккаунт.
- Поиск: Используйте главную строку поиска для нахождения релизов. Фильтруйте результаты по CD, винилу или кассете.
- Управление: Добавляйте релизы в вашу «Коллекцию» или «Список желаемого».
- Организация: Используйте переключатели «Сетка/Список», сортируйте по году или названию, добавляйте личные заметки к вашим релизам.
- Экспорт: Нажмите «Экспорт CSV» в разделе «Коллекция», чтобы скачать ваши данные.
